# Хилсорт — тестовая игра

Статическая страница звёздного атласа с Олионом. Режим проверки включён по умолчанию: выберите любой шаг, используйте «Назад» / «Следующий шаг» или «Показать все 30».

Профиль, заметки и прогресс остаются в браузере. Тестовые переходы не создают отметок приёма и не списывают капсулы. Отправка уведомлений в Telegram/MAX и подтверждение покупок в этой версии не подключены.

`?review=0` включает обычное ежедневное открытие. `npm test` запускает проверки. GitHub Pages публикует корень ветки `main`.

Библиотеки и лицензии: Astronomy Engine (MIT), каталоги d3-celestial, шрифт Manrope (OFL). Лицензии сохранены в `assets/`. Олион и материалы Хилсорт используются для предпросмотра бренда.
